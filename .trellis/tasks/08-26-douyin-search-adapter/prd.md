# 抖音搜索适配

## Goal

让用户在现有“采集任务”页面选择抖音，使用已保存的监控规则在用户批准的谷歌浏览器
会话中执行一次有边界的关键词搜索，并把可打开的抖音作品链接作为统一搜索运行和去重
结果保存、展示。

## Background

- 产品搜索现已支持今日头条、微博和快手，运行、来源词、新旧判断、取消、SQLite 持久化
  和前端详情可以继续扩展。
- 抖音账号检测和可见登录流程已经复用用户批准的谷歌浏览器；滑块或其他安全验证明确
  交给用户人工完成，不自动绕过。
- MediaCrawler 当前抖音搜索调用官方网页使用的综合搜索接口，但通用路径会读取完整
  LocalStorage、记录关键词和结果、写入通用存储，并继续抓评论和媒体。
- 当前综合搜索接口已有稳定 `aweme_id`、作品描述、发布时间和作者字段，但还没有产品级
  严格协议、终态分类和真实复跑验收。

## Requirements

### Search behavior

- 采集任务页面增加抖音作为真实可执行平台，不显示为占位选项。
- 首版复用 MediaCrawler 已验证的抖音官方网页综合搜索接口，不新增独立浏览器，也不调用
  通用 `DouYinCrawler.search()`。
- 每个规则词按 OR 语义独立、顺序执行；同一作品在一次运行中只显示一次，并保留全部
  命中词。
- 搜索沿用现有 1–20 个规则词、每词 1–50 条、取消和全局浏览器串行约束。
- 首版使用抖音默认综合排序，不增加排序或发布时间控件。
- 结果至少包含稳定作品 ID、可读作品描述、规范化原文链接、平台发布时间、脱敏发布者
  以及首次和最近发现时间。
- 产品搜索只发现作品；不请求详情、评论、作者主页、封面、图片、视频、音乐或其他媒体。

### Outcomes and safety

- 搜索前必须通过抖音现有权威在线探测；明确未登录返回 `login_required`，并引导用户到
  “平台账号”处理。
- 空结果、需要登录、滑块或其他人工安全验证、访问限制或限流、响应结构变化、浏览器
  不可用、取消和内部错误必须明确区分，不得伪装成成功空结果。
- 每个搜索分页请求只发送一次；不得自动重试、指数退避、代理切换或备用浏览器回退。
- 只在任务自己创建的抖音页面读取搜索所需的最小临时状态；不得读取完整 LocalStorage、
  向共享 BrowserContext 安装全局脚本，或关闭、修改用户原有标签页。
- Cookie、最小临时令牌、原始响应、原始异常、未脱敏作者身份和关键词日志不得进入产品
  API、前端、任务证据或不受控日志。
- 已安全规范化并持久化的部分结果可在后续终态失败时保留，但运行状态必须保持真实。

### Compatibility

- 复用现有搜索运行、SQLite 全局内容、运行观察和来源词关系；抖音内容使用
  `(dy, platform_content_id)` 去重。
- 已有今日头条、微博和快手运行、结果、链接、计数和迁移数据保持不变。
- 平台账号检测、监控规则、常驻 worker、全局浏览器互斥和现有路由保持兼容。

## Acceptance Criteria

- [x] 用户可以在采集任务中选择抖音并启动持久化运行，HTTP 202 不等待完整浏览器搜索。
- [x] 全部规则词按 OR 语义执行；同一抖音作品在一次运行中只出现一次并保留全部命中词。
- [x] 相同作品再次命中时不新增全局内容行，标记为历史内容再次命中，保留首次发现时间并更新最近发现时间。
- [x] 原文链接严格规范化为无查询参数和片段的 `https://www.douyin.com/video/<作品ID>`，并与平台和作品 ID 相互校验。
- [x] 产品适配器每页至多请求一次，不抓详情、评论、主页或媒体，不写 MediaCrawler 通用存储，也不记录关键词或原始响应。
- [x] 登录、安全验证、限流、协议变化、取消和浏览器故障均映射为真实终态，不会成为成功空结果。
- [x] 结束或取消搜索只清理任务自己创建的页面；用户原有标签页、谷歌浏览器和常驻连接可继续使用。
- [x] MediaCrawler、FastAPI、SQLite 迁移、React、跨层协议和真实谷歌浏览器复跑验收通过，已有三个搜索平台和账号检测无回归。

## Out of Scope

- 评论、详情补全、转发链、完整作者资料、媒体下载、账号池和历史回填。
- 自动重试、定时调度、断点续跑以及验证码、滑块、短信或其他安全验证绕过。
- 抖音排序、发布时间、内容类型、页数或并发设置。
- 小红书搜索适配。

## Key Decisions

- 2026-08-26：复用 `/aweme/v1/web/general/search/single/` 的现有综合搜索能力，但建立
  独立产品客户端；不调用通用爬虫、通用存储、评论和媒体链路。
- 2026-08-26：搜索接口当前不需要 MediaCrawler 的 `a_bogus` 分支；只读取任务页面中
  接口所需的单个临时值。若真实验收重新要求更侵入式签名或浏览器全局状态，停止实施并
  返回规划，不追加绕过。
- 2026-08-26：每页按接口当前 15 条能力估算，最多请求
  `ceil(max_results_per_term / 15)` 页，并在达到用户上限后立即停止。
