# 小红书搜索适配

## Goal

让用户在现有“采集任务”页面选择小红书，使用已保存的监控规则在用户批准的谷歌浏览器
会话中执行一次有边界的关键词搜索，把笔记作为统一搜索运行和去重结果保存、展示，并可在
不持久化小红书访问令牌的前提下按需打开原文。完成后，甲方要求的今日头条、微博、快手、
抖音和小红书五个平台均具备同一套手动搜索链路。

## Background

- 产品搜索现已支持今日头条、微博、快手和抖音，运行历史、来源词、新旧判断、取消、
  SQLite 持久化和前端详情可以继续扩展。
- 小红书账号检测已复用用户批准的谷歌浏览器，并通过官方在线接口确认登录；历史实测发现
  小红书搜索页面的导航完成事件不稳定，因此搜索不能依赖页面“加载完成”来证明成功。
- 2026-08-26 的脱敏真实诊断确认：一个成功首屏可同时包含 14 条安全笔记、2 张已知辅助
  卡片和 6 张其余结构合法但标题归一化为空的笔记卡。空标题不是整页结构漂移证据。
- 2026-08-26 的真实搜索和同规则复跑已完成全部五个词，并证明跨运行去重、首次/最近发现
  时间与无参数 ID 链接持久化正常；但直接打开一个规范 ID 链接被小红书以业务错误 300031
  重定向到“当前笔记暂时无法浏览”。稳定 ID 可以作为内容身份，不能保证网页可直接打开。
- MediaCrawler 已有小红书搜索 API 和签名能力，但通用流程会重试、抓笔记详情、评论和
  媒体，记录关键词与响应，并把搜索结果令牌写入通用存储，不符合产品边界。
- 小红书风控比其他平台严格。验证码、滑块、短信和其他安全验证必须继续由用户人工完成，
  产品不自动绕过。

## Requirements

### Search behavior

- 采集任务页面增加小红书作为真实可执行平台，不显示为占位选项。
- 每个规则词按 OR 语义独立、顺序执行；同一笔记在一次运行中只显示一次，并保留全部
  命中词。
- 搜索沿用现有 1–20 个规则词、每词 1–50 条、取消和全局浏览器串行约束。
- 首版使用小红书默认综合排序并包含图文与视频笔记，不增加排序、发布时间或类型控件。
- 结果至少包含稳定笔记 ID、搜索卡片标题、规范化原文链接、可用时的笔记类型和脱敏
  发布者，以及首次和最近发现时间。
- 对 ID、`note_card` 和笔记类型均合法，但 `display_title` 缺失、为 null 或空白字符串的
  已识别笔记卡，只忽略该卡片；不得伪造标题。缺失或非法 ID、缺失 `note_card`、未知模型/
  笔记类型及其他畸形非空结构仍返回结构变化。
- 搜索卡片未提供正文或发布时间时允许对应展示字段为空；不得为了补齐字段额外请求
  笔记详情。
- 产品搜索只发现笔记；不请求详情、评论、作者主页、图片、视频或其他媒体。

### Open-original behavior

- 小红书结果仍保存严格无查询参数的规范 ID 链接，作为可验证的内容身份；前端不得把它
  直接渲染为小红书外链。
- 小红书结果显示 Shadcn `Button`“打开原文”。点击后调用
  `POST /api/v1/search-runs/{run_id}/results/{result_id}/open`；其他平台继续使用现有普通外链。
- 后端只能打开确实属于该运行的小红书结果，并从 SQLite 读取稳定笔记 ID 与第一个已保存
  命中词。客户端不得提交任意笔记 ID、搜索词、令牌或目标 URL。
- 打开操作复用全局浏览器互斥，在一个同步、有超时的请求中完成。浏览器忙时返回既有 409，
  不建立第二套任务表、队列或轮询状态。
- MediaCrawler 对已保存的第一个命中词只执行一次首页搜索请求，在内存中匹配目标笔记 ID。
  找到后只读取该卡片中有界且非空的 `xsec_token`；固定搜索渠道标识由 worker 根据本次搜索
  操作推导为 `pc_search`，不读取或信任响应提供的来源字段。二者仅用于任务自建页面导航；
  不得自动翻页、换词、重试、抓详情或回退到无令牌链接。
- 打开成功后，该页面解除任务所有权并交给用户继续浏览；失败时只清理任务自建页面。登录或
  人工验证页面可以保持可见，但必须返回明确结果。
- 打开操作返回固定结果：`opened`、`content_not_found`、`content_unavailable`、
  `login_required`、`manual_challenge_required`、`platform_blocked_or_rate_limited`、
  `structure_changed`、`browser_unavailable` 或 `internal_error`。不得把失败包装为已打开。

### Outcomes and safety

- 搜索前必须通过小红书现有权威在线探测；明确未登录返回 `login_required`，并引导用户
  到“平台账号”处理。
- 空结果、需要登录、人工安全验证、访问限制或限流、响应结构变化、浏览器不可用、取消
  和内部错误必须明确区分，不得伪装成成功空结果。
- 每个搜索分页请求只发送一次；不得自动重试、指数退避、代理切换或备用浏览器回退。
- 只使用任务自己创建的官方页面和按小红书域名限定的 Cookie；不得读取 LocalStorage、
  安装共享 BrowserContext 脚本，或关闭、修改用户原有标签页。
- Cookie、签名值、搜索结果令牌、原始响应、原始异常、未脱敏作者身份和关键词日志不得
  进入产品 API、前端、任务证据或不受控日志。
- 持久化原文身份链接只由稳定笔记 ID 构造，不保留 `xsec_token`、`xsec_source` 或其他
  查询参数。令牌只允许在一次 MediaCrawler 打开调用的内存和任务自建页面导航中存在，
  不得进入 SQLite、worker 事件、FastAPI 响应、前端状态、日志或测试证据。
- 已安全规范化并持久化的部分结果可在后续终态失败时保留，但运行状态必须保持真实。

### Compatibility

- 复用现有搜索运行、SQLite 全局内容、运行观察和来源词关系；小红书内容使用
  `(xhs, platform_content_id)` 去重。
- 已有今日头条、微博、快手和抖音运行、结果、链接、计数和迁移数据保持不变。
- 平台账号检测、监控规则、常驻 worker、全局浏览器互斥和现有路由保持兼容。

## Acceptance Criteria

- [x] 用户可以在采集任务中选择小红书并启动持久化运行，HTTP 202 不等待完整浏览器搜索。
- [x] 全部规则词按 OR 语义执行；同一笔记在一次运行中只出现一次并保留全部命中词。
- [x] 相同笔记再次命中时不新增全局内容行，标记为历史内容再次命中，保留首次发现时间并更新最近发现时间。
- [x] 原文链接严格规范化为无凭据、端口、查询参数和片段的 `https://www.xiaohongshu.com/explore/<笔记ID>`，并与平台和笔记 ID 相互校验。
- [x] 小红书结果不直接导航规范 ID 链接；点击“打开原文”只提交运行 ID 与结果 ID，后端从
  已保存关系取得目标 ID 和首个命中词，并在浏览器全局互斥内执行一次按需打开。
- [x] 按需打开只请求一次搜索首页，不翻页、不换词、不重试；成功时令牌只用于 worker 内
  任务页导航，固定 `pc_search` 渠道标识只由 worker 推导且页面交给用户；API/SQLite/前端/
  日志中均不存在 `xsec_token`/`xsec_source`。
- [x] 目标未重新出现、笔记不可访问、未登录、人工验证、限流、结构变化和浏览器故障均在
  按钮附近给出明确中文反馈；HTTP/协议失败不显示“已打开”。
- [x] 产品适配器每页至多请求一次，不抓详情、评论、主页或媒体，不写 MediaCrawler 通用存储，也不记录关键词、签名值、令牌或原始响应。
- [x] 合法空标题卡与已知辅助卡不会中断同页安全结果；若一个连贯完成的响应只有这些卡，
  运行明确结束为成功空结果且不会合成占位标题。
- [x] 登录、安全验证、限流、协议变化、取消和浏览器故障均映射为真实终态，不会成为成功空结果。
- [x] 结束或取消搜索只清理任务自己创建的页面；用户原有标签页、谷歌浏览器和常驻连接可继续使用。
- [x] MediaCrawler、FastAPI、SQLite 迁移、React、跨层协议和真实谷歌浏览器复跑验收通过，已有四个搜索平台和五个平台账号检测无回归。

## Out of Scope

- 笔记详情补全、评论、转发链、完整作者资料、图片或视频下载、账号池和历史回填。
- 自动重试、定时调度、断点续跑以及验证码、滑块、短信或其他安全验证绕过。
- 小红书排序、发布时间、笔记类型、页数或并发设置。
- 持久化、加密或刷新 `xsec_token`，为打开原文自动尝试多个词或多页，以及后台打开队列/
  历史记录。
- 海外版 RedNote 搜索。
- AI 情绪判断、风险分级、摘要、告警和日报。

## Key Decisions

- 2026-08-26：复用国内版小红书官方网页搜索 API 和现有纯算法签名能力，但建立独立
  产品客户端；不调用通用爬虫、通用重试、通用存储、详情、评论和媒体链路。
- 2026-08-26：首版只使用搜索结果卡片中已有的标题、类型和作者信息；缺失的正文与
  发布时间保持为空。
- 2026-08-26：脱敏真实响应证明合法空标题卡可与安全结果共存；适配器只跳过该窄类卡片，
  全部为合法空标题/辅助卡且分页连贯结束时返回成功空结果，其他畸形结构继续失败关闭。
- 2026-08-26：规范 ID 链接真实打开失败后，用户批准改为按需打开。SQLite/API/前端仍只
  保存和传递稳定 ID；worker 使用首个已保存命中词执行一次搜索，在内存中取得令牌并直接
  导航任务页。令牌不持久化、不跨 worker 边界，也不为提高命中率自动多词或多页重试。
- 2026-08-26：脱敏 live correction 证明搜索卡提供有效 token 但不提供 source；用户批准
  worker 从唯一受信搜索操作固定推导 `pc_search`，不读取响应 source。修正后的真实打开
  返回 `opened`，后端退出后标签页仍保留且官方规范路径、可见笔记内容与无失效/验证提示
  均成立；SQLite 与 API 未出现 xsec 值。
