# 快手搜索适配

## Goal

让用户在现有“采集任务”页面选择快手，使用已保存的监控规则在用户批准的谷歌浏览器会话中执行一次有边界的关键词搜索，并把可打开的快手作品链接作为统一搜索运行和去重结果保存、展示。

## Background

- 产品搜索现已支持今日头条和微博，搜索运行、来源词、新旧判断、取消、SQLite 持久化和前端详情可以继续扩展。
- 快手账号检测已经通过常驻 worker 复用用户批准的谷歌浏览器，并将签名脚本限制在任务自己创建的页面。
- MediaCrawler 当前快手搜索使用页面内 `$encode` 生成 `__NS_hxfalcon`，随后调用 `/rest/v/search/feed`。通用路径还会强制至少抓取 20 条、自动重试限流、记录关键词、写入通用存储并继续抓评论。
- 快手作品已有稳定 `photo.id`、标题、发布时间、匿名创作者字段以及标准原文链接，但还没有产品级严格协议、终态分类和真实复跑验收。

## Requirements

### Search behavior

- 采集任务页面增加快手作为真实可执行平台，不显示为占位选项。
- 首版复用 MediaCrawler 已验证的页面内签名机制和快手官方网页搜索接口，不新增独立浏览器或可见 DOM 解析器。
- 每个规则词按 OR 语义独立、顺序执行；同一作品在一次运行中只显示一次，并保留全部命中词。
- 搜索沿用现有 1–20 个规则词、每词 1–50 条、取消和全局浏览器串行约束。
- 首版使用快手默认搜索排序，不增加排序控件。
- 结果至少包含稳定作品 ID、可读标题或正文、规范化原文链接、平台发布时间、脱敏发布者以及首次和最近发现时间。
- 产品搜索只发现作品；不请求详情、评论、用户主页、封面、图片、视频或其他媒体文件。

### Outcomes and safety

- 搜索前必须通过快手现有权威在线探测；未登录返回 `login_required`，并引导用户到“平台账号”处理。
- 空结果、需要登录、人工安全验证、访问限制或限流、签名或响应结构变化、浏览器不可用、取消和内部错误必须明确区分，不得伪装成成功空结果。
- 每个搜索页请求只发送一次。不得沿用通用客户端的三次限流重试、指数退避或原始响应异常文本。
- 只允许在任务自己创建的快手页面安装现有签名捕获脚本；不得向用户共享 BrowserContext 安装全局脚本，也不得关闭或修改原有标签页。
- 平台原始响应、签名、Cookie、认证头、LocalStorage、原始异常、未脱敏创作者身份和关键词日志不得进入产品 API、前端、任务证据或不受控日志。
- 已安全规范化并持久化的部分结果可在后续终态失败时保留，但运行状态必须保持真实。

### Compatibility

- 复用现有搜索运行、SQLite 全局内容、运行观察和来源词关系；快手内容使用 `(ks, platform_content_id)` 去重。
- 已有今日头条和微博运行、结果、链接、计数和迁移数据保持不变。
- 平台账号检测、监控规则、常驻 worker、全局浏览器互斥和现有路由保持兼容。

## Acceptance Criteria

- [x] 用户可以在采集任务中选择快手并启动持久化运行，HTTP 202 不等待完整浏览器搜索。
- [x] 全部规则词按 OR 语义执行；同一快手作品在一次运行中只出现一次并保留全部命中词。
- [x] 相同作品再次命中时不新增全局内容行，标记为历史内容再次命中，保留首次发现时间并更新最近发现时间。
- [x] 原文链接严格规范化为无查询参数和片段的 `https://www.kuaishou.com/short-video/<作品ID>`，并与平台和作品 ID 相互校验。
- [x] 产品适配器每页至多请求一次，不抓详情、评论、主页或媒体，不写 MediaCrawler 通用存储，也不记录关键词或原始响应。
- [x] 登录、安全验证、限流、签名或协议变化、取消和浏览器故障均映射为真实终态，不会成为成功空结果。
- [x] 结束或取消搜索只清理任务自己创建的页面；用户原有标签页、谷歌浏览器和常驻连接可继续使用。
- [x] MediaCrawler、FastAPI、SQLite 迁移、React、跨层协议和真实谷歌浏览器复跑验收通过，今日头条、微博和账号检测无回归。

## Out of Scope

- 评论、详情补全、转发链、完整用户资料、媒体下载、账号池和历史回填。
- 自动重试、定时调度、断点续跑以及验证码、滑块、短信或其他安全验证绕过。
- 快手排序、筛选、页数或并发设置。
- 抖音和小红书搜索适配。

## Key Decisions

- 2026-08-26：首版复用任务页面内的快手签名机制和 `/rest/v/search/feed`，但使用独立产品客户端；不调用 `KuaishouCrawler.search()` 或通用三次重试客户端。
- 2026-08-26：快手每页固定按现有 20 条能力估算，最多请求 `ceil(max_results_per_term / 20)` 页，并在达到用户上限后立即停止。
- 2026-08-26：首版固定平台默认排序，不增加用户设置；排序需求留给真实结果质量验证后再决定。
