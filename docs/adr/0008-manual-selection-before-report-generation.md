# 手动采集与选材生成报告分开，自动化另行设计

2026-09-06：[ADR-0011](0011-text-only-analysis-scope.md) 明确文字理解切换后的总结复用边界，旧底座总结不再用于新报告；下文的“可用总结”须满足该边界，其余选材与报告流程继续有效。

为让使用者从积累的内容库决定报告来源，手动流程分为独立的舆情爬取入库，以及在报告生成界面选材后启动分析。报告生成界面以生成一份报告为主任务，同时展示全部舆情内容库作为选材来源；内容库不是第三个业务阶段。逐条勾选和批量选材都只形成可见且可修改的报告选材集合，不直接启动分析，后来入库的内容不会悄悄加入已经形成的集合。使用者统一点击“生成报告”，在确认界面填写本次报告信息后才提交。提交后自动完成必要补全、单条总结和报告汇总，复用选中条目已有的可用总结，不自动加入未选中的历史内容，并显示进度、报告和条目处理情况。采集到报告的一键编排及自动分析授权归入自动任务，不在手动报告生成界面配置；本决定取代 ADR-0004 对日常手动流程的约定，但不改变登录或安全验证时由用户显式继续的异常恢复规则。
