# 浏览器发现内容与受控的第三方内容获取分离

2026-09-06：本版图片、视频获取与分析范围已由 [ADR-0011](0011-text-only-analysis-scope.md) 改为原帖文字理解；下文保留既有实现与决策背景，浏览器发现和受控原帖获取的职责边界继续有效。

为减少平台适配的自维护负担，本项目接受由自有浏览器采集层发现内容链接、可替换开源组件解析指定内容和下载媒体的混合方式，允许组件内部请求平台接口，不要求全部数据获取通过浏览器页面操作完成。应用保留任务范围、进度、请求预算、人工暂停恢复、结果校验和入库的控制权，只有行为可审查、可约束的组件才能接入；补全确有需要时，允许本地组件在指定任务中使用本项目对应平台的必要登录态，不读取日常浏览器或其他平台的登录态、不交付给第三方数据服务。当前微博补全由锁定版本的 gallery-dl 获取器执行正文提取和媒体下载，应用通过受限请求桥接掌握网络边界、凭证域名范围、预算和媒体缓存，避免把获取器降级为仅解析 JSON 的适配器。代价是仍依赖第三方维护和平台接口行为，不能据此承诺降低风控；普通 403 只记录为访问拒绝，只有检测到明确登录、安全验证或限流证据时才暂停等待人工继续。

断点续作时，应用只把尚未完成的媒体重新交给同一获取器下载任务，不重复正文请求；失败阶段、状态码和分类依据以脱敏、限长诊断保存，凭证与带签名媒体地址不进入持久化记录。
