# 浏览器发现内容与受控的第三方内容获取分离

为减少平台适配的自维护负担，本项目接受由自有浏览器采集层发现内容链接、可替换开源组件解析指定内容和下载媒体的混合方式，允许组件内部请求平台接口，不要求全部数据获取通过浏览器页面操作完成。应用保留任务范围、进度、请求预算、人工暂停恢复、结果校验和入库的控制权，只有行为可审查、可约束的组件才能接入；补全确有需要时，允许本地组件在指定任务中使用本项目对应平台的必要登录态，不读取日常浏览器或其他平台的登录态、不交付给第三方数据服务。代价是仍依赖第三方维护和平台接口行为，不能据此承诺降低风控；具体工具和凭证传递方式仍须审查，本轮不提取凭证或开展平台试验。
