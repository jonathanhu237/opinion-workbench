# 发现去重与条目处理策略分离

搜索阶段负责发现、去重和入库，分析失败不会使一个已发现条目重新成为新增。后续批量选材统一选择内容库中所有尚无可用成功总结的未分析条目，包括从未处理和当前分析失败的内容，不再要求使用者决定是否包含失败项，也不要求失败内容在本次搜索中再次命中。分析失败仍保留为可诊断状态；每次使用者明确发起时为当前失败条目创建一次新的分析尝试，不在一次任务中无限重试，也不覆盖旧记录；后来取得可用总结后即退出未分析集合。该规则将采集批次与分析候选解耦，并让选材面向业务结果而不是技术历史；手动流程的选材与启动边界遵循 ADR-0008。
