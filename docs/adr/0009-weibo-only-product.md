# 当前产品只保留微博平台能力

当前产品从界面、业务规则、接口约束和运行时都只保留微博，不再把抖音、快手、小红书和今日头条建模为暂时停用的平台；旧平台代码、资产、测试兼容、应用数据与本地备份一并移除，MediaCrawler 子模块及其未提交修改不留档。内容继续保留平台字段，但当前合法值只有 `wb`，未来增加其他平台时按新的接入能力重新实现。删除当前 4 条没有运行记录的旧多平台自动任务和 23 份含非微博内容的本地数据库备份；保留 AI 配置、监控规则、微博浏览器登录目录和必要的旧数据库迁移链，并以最终迁移将运行时表约束收紧到 `wb`。历史研究文档保留为决策过程记录。本决定取代 ADR-0005 中“保留其他平台历史兼容并逐一恢复”的迁移策略，以降低当前产品复杂度和误导性入口，代价是未来重新接入平台时不复用旧实现或旧数据。
