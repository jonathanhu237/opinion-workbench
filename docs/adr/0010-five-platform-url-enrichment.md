# 在已验证的微博链路上重新接入四个平台

2026-09-06：本版图片、视频获取与分析范围已由 [ADR-0011](0011-text-only-analysis-scope.md) 改为原帖文字理解；下文保留最初决策背景，五平台接入范围与其他职责边界继续有效。

微博完整流程验证后，产品范围扩展为微博、抖音、快手、小红书和今日头条，覆盖关键词采集、平台登录、内容库、报告生成和自动任务；内部逐个平台适配和验收，最终交付五个平台的完整流程。沿用 ADR-0003 的浏览器发现内容 URL、可替换本地组件补全指定原帖和媒体的职责分工，以及 ADR-0008 的采集入库与手动选材分离，避免重新引入旧采集运行时；各平台的页面、内容形式和组件能力仍须单独验证。

本决定取代 ADR-0009 的微博单平台产品范围，不撤销已完成的数据清理，也不恢复 MediaCrawler 或旧平台数据。既有微博数据、报告、配置和登录状态应保留；新增平台按新能力接入，ADR-0002 的整批人工暂停与显式继续规则保持有效。代价是需要重新扩展平台约束并承担四个平台各自的适配维护，不能把微博验收结果当作其他平台已可用的证明。

补全优先验证现成工具，允许按平台和内容类型组合正文提取与媒体下载组件，并在实际缺口明确后增加必要的专属适配；不以统一工具数量为目标，也不在完成工具调查前预设从零编写获取器。今日头条包含文章全文、微头条和独立视频，因此“支持头条视频”不能代替整个平台的内容覆盖。
