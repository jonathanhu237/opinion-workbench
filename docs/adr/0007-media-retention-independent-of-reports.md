# 报告引用不阻止原媒体按保留策略清理

> 本决定的媒体保留策略和“不授权当前立即删除文件”边界已由
> [ADR-0012](0012-media-cache-exit.md) 取代。以下内容保留为历史背景。

为控制本地存储占用，已被报告引用的图片和视频仍受可配置的保存期限与容量上限约束，允许按媒体保留策略清理。清理保留正文、单条总结、报告、来源及当时的处理记录，并明确原媒体已不在本地。代价是历史报告不保证原图或视频仍可回看，报告留存不等于永久保存原始媒体；本决定不授权当前立即删除文件。
