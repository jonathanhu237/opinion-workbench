# 完全退出当前产品的媒体缓存与本地媒体回看

当前产品的内容补全和文字理解以原帖文字为依据。图片、视频和声音不再下载、保存、读取或送入分析；设置、详情、报告和 API 也不再提供媒体缓存配置、保留策略或本地媒体回看入口。旧版本中的媒体保留策略只作为历史背景，不再是当前领域能力。

用户于2026-09-09明确确认完整退出媒体能力，并授权删除本项目管理的已有媒体文件。升级到本决定时，应用执行一次受管媒体清理：原媒体缓存依据目录权限、缓存所有权记录和文件 inode 核实归属；临时媒体依据私有目录权限、操作 UUID 与不透明文件名识别。只清理符合这些受管规则的媒体文件。混入的非媒体资料、未知条目、数据库、截图、日志、浏览器资料、密钥和其他运行数据保留。受管文件的实际文件系统删除失败时，迁移保留旧数据库版本及所有权索引并报告可重试错误；恢复文件系统条件后再次启动可以继续清理。无法证明归属的目录或条目不阻塞数据库升级。

正文资料、来源信息、原帖链接、舆情内容库、单条总结、舆情报告、报告记录、处理记录和其他文字历史继续保留并可复用。历史媒体元数据可以继续出现在保存的输入记录中，用于说明当时的处理边界，但不承诺本地媒体仍可回看；需要图片、视频或声音信息时，使用者应打开原帖。退出媒体能力不触发全库重跑或删除历史报告。

代码中保留的旧媒体模块仅限迁移清理、旧数据结构和未挂载的兼容测试边界，不构成生产装配、路由、运行时状态或真实媒体读写入口。后续新增功能不得依据这些历史模块恢复媒体缓存或媒体保留配置，除非重新形成架构决策。

本决定取代 [ADR-0007](0007-media-retention-independent-of-reports.md) 关于报告引用后仍按媒体保留策略清理的产品边界，并修订 [ADR-0011](0011-text-only-analysis-scope.md) 中“不因此自动清理媒体”的历史说明；ADR-0011 关于原帖文字理解、信息不足条目和人工核查提示的其余内容继续有效。
