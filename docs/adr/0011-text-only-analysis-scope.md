# 五平台接入先限定为原帖文字理解

五平台仍覆盖关键词采集、登录、内容库、报告和自动任务，本版的内容分析限定为原帖标题、完整正文或配文及话题标签，保留可取得的作者、发布时间、互动统计和原帖链接。为降低媒体下载、存储、转码和多模态分析的复杂度，用户明确接受仅存在图片、视频画面或声音中的信息可能遗漏；本版不执行媒体理解，也不以 OCR 或语音转写作为替代。此前 URL 探针只验证了内容获取，不能作为实际多模态理解质量差或费用不可接受的证据。

本决定取代 [ADR-0003](0003-controlled-hybrid-collection.md) 和 [ADR-0010](0010-five-platform-url-enrichment.md) 中本版需要获取并分析图片、视频的范围，以及设计讨论中 50 张图片、10 分钟视频画面与音轨的完整分析目标；保留浏览器发现、受控原帖获取、正文全文补全及人工暂停恢复的边界。搜索摘要不能代替原帖全文，媒体传输、分段和媒体补缺入口退出本版范围；现有历史数据与报告继续保留，媒体退出和既有文件清理按 [ADR-0012](0012-media-cache-exit.md) 执行，不批量重跑总结。

2026-09-09：本决定中关于“现有历史数据与报告继续保留，但不因此自动清理媒体”的边界由 [ADR-0012](0012-media-cache-exit.md) 修订。文字理解仍限定为原帖文字；当前产品同时完全退出媒体缓存、媒体保留策略和本地媒体回看，按 ADR-0012 执行一次性受管媒体清理。历史数据、报告和文字资料继续保留，不因退出媒体而批量重跑总结。

原帖文字不足、无法判断的条目必须出现在交付报告中，明确提示人工查看原帖，不能只留在任务处理日志中，也不能写成已确认事实。即使本次所有条目均文字不足，仍交付可阅读报告，注明“无法通过文字判断是否和舆情有关”，逐条提供已有文案、核查原因和原帖链接；不能把无法判断表述为无关或没有舆情。该信息不足情况是文字理解范围的业务结果，不等同于登录、安全验证引起的采集暂停，也不把模型配置或运行故障当作报告完成。

本次切换前旧底座生成的总结一律不作为新报告的可复用总结，包括旧流程中恰好仅用了文字的总结；新分析统一依据原帖文字。历史报告和旧总结仍保留，新任务只处理本次选中的来源，不启动全库批量重跑；新底座下生成的文字总结之后按既有规则复用。本规则细化 [ADR-0008](0008-manual-selection-before-report-generation.md) 的“可用总结”边界，代价是旧条目首次被新流程处理时需要重新进行文字理解。
