# 五平台关键词采集与文字舆情分析

Status: implemented

2026-09-06：grill-with-docs 讨论已完成。本文件汇总当前已确认的产品范围，供实施和验收使用。

## 目标

在现有微博链路上接入抖音、快手、小红书、今日头条，形成五平台的关键词采集、登录、内容库、选材、报告和自动任务流程。本版 AI 只理解原帖文字，用户明确接受仅存在图片、视频画面和声音中的信息可能遗漏。

## 采集与运行

- 手动采集和新建自动任务默认全选五个平台，允许调整；既有任务保留原先保存的平台范围。
- 从各平台关键词搜索发现内容；每个平台对每个词独立计算采集上限，不足时保留实际结果。平台可用最新排序时使用最新，否则记录实际顺序。
- 同平台按内容身份去重，URL 变体不创建重复内容；跨平台转载保留独立来源，不新增相似内容合并。
- 采集独立入库，手动报告使用用户明确选中的内容；自动任务沿用现有编排。
- 平台普通失败继续其他平台并在报告中记录采集缺口；登录、安全验证等人工障碍使同一批次整体暂停，用户处理后显式继续。
- 前后端、SQLite、浏览器/CDP 和平台登录均在本地运行。保留现有微博数据、报告、配置和项目浏览器状态；不恢复被清理的旧平台数据或 MediaCrawler。

## 文字获取与理解

- 获取原帖标题、完整正文或配文、话题标签，以及可取得的作者、发布时间、互动统计和原帖链接。作者沿用现有昵称脱敏规则；未知时间、统计如实标为未知，不能以零代替。
- 今日头条覆盖文章、微头条和独立视频帖的原帖文字；文章正文须为全文，搜索摘要和标题不能代替全文。其他平台同样处理展开文案和长正文。
- 原帖引用或转发文字保留归属；获取范围不延伸到评论、回复或关联推荐。此版不新增手动粘贴 URL、账号主页或榜单采集入口。
- 优先复用已验证组件的单作品文字获取能力，必要时组合或做最小适配；应用继续控制请求范围、预算、凭证、校验、缓存、取消和人工恢复。本项目登录态只用于对应平台所需请求。
- 模型内容输入只包含文字及来源信息，图片、视频和音轨不参与新分析，也不采用 OCR 或语音转写。新流程不为内容分析下载媒体文件；历史媒体沿用原保留策略，不因本次改版立即清理。
- 保留必要的原帖文字补全，不能把仅给模型 URL 后返回的联网摘要视为五平台全文获取已经完成。已有 URL 实测只作为组件选择依据。
- 文案短不自动等于信息不足：只要足以表达具体事件并支持判断，仍正常分析。无法判断时保留不确定性，不从未读取的图片或声音推断事实。

## 报告与人工核查

- 文字足够且与主题相关的来源可形成报告分析；因文字不足无法判断的来源，必须在实际可阅读报告中显式列为待人工核查条目。
- 待核查条目提供已有文案、无法判断的原因和原帖链接，并提示“无法通过文字判断是否和舆情有关”，供读者打开原帖查看。不能只在任务日志中提示，也不能把这类条目写成已确认事件、无关来源或没有舆情。
- 混合来源的报告同时呈现可形成的分析与待人工核查条目；即使全部条目文字不足，也交付可阅读报告，使用相同说明并完整列出待核查条目。
- 文字不足是可交付的业务结果；模型配置错误、服务故障、采集未完成及尚待登录等运行问题仍按对应失败/暂停规则处理。没有发现任何内容与已有来源但文字不足是不同情况。
- 人工查看通过报告提示和原帖链接完成；本次范围不增加审核人分配、复核回填或审核工作台。

## 新旧结果与复用

- 切换前旧底座生成的所有总结均不作为新报告的可复用总结，包括旧流程中恰好只分析了文字的总结。
- 新任务仅按本次选材重新形成文字总结，可复用已取得且对应原帖的正文，缺失时再获取；不把旧总结当成正文重新概括，不批量重跑未选中的历史内容。
- 新底座的文字总结之后按既有规则复用。手动选材与自动流程均须遵守新旧结果边界，不能让任一缓存路径绕过该规则。
- 历史报告、旧总结和失败尝试保留；旧报告的来源和证据保持其生成时的状态。

## 验收

1. 五个平台分别完成真实关键词发现、登录/人工暂停与继续、去重入库、文字补全、选材生成报告和自动任务验证；接口、数据库和界面均接受五平台，不能只添加选项。
2. 验证新建默认全选、既有任务范围保留、各平台每词独立计数、排序标注，以及普通平台失败继续其他平台和报告缺口说明。
3. 验证长正文/头条全文与视频帖配文等文字输入，保留作者脱敏及未知字段语义；实际新模型请求无图片、视频或音轨，媒体缺失不再构成文字分析的缺口。
4. 用明确短文案、模糊文案、只有标签/无有效文字等情形验证是否有依据判断；混合报告和全部文字不足报告均可阅读，核查原因与原帖链接可见，提示语不把无法判断写成无关或无舆情。
5. 使用旧多媒体总结和旧纯文字总结分别验证：新报告均重新进行文字理解，历史报告保留；新文字总结能按新规则复用，未选中内容不被重跑。
6. 验证模型配置错误、普通技术失败、登录暂停与文字不足分别保持正确语义；“全部文字不足仍有报告”不掩盖运行故障。

本次撤下的 50 张图片、10 分钟视频、原音轨输入、媒体分段和媒体补缺入口不作为验收要求。工具探针成功不替代上述应用流程验收。
