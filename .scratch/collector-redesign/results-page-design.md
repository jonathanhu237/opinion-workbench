# 报告生成页面设计记录

Status: discussion-complete

## 已确认

- 左侧入口以“报告生成”为名，生成报告是页面主任务；全部舆情内容仍作为选材来源展示。
- 自动分析授权与设置移出本页面，归入“自动任务”。
- 首版使用 Shadcn 风格的 Data Table 展示内容，不提供筛选。
- 用户可以逐条勾选，也可以一键选中全部未分析条目；未分析统一指当前没有可用成功总结，包括从未处理和当前分析失败的条目，不再提供是否包含失败项的选择。
- 批量选材在点击时固定集合，后来入库的内容不会自动加入；用户提交前可以取消其中任意条目。
- 条目状态仍区分“待分析”和“分析失败”，批量选材统一使用“未分析内容”。
- 内容表格最新入库优先，每页二十条，跨页保留选择。
- 默认列为：选择、平台、内容摘要、素材、发布时间、分析状态、操作。首次发现时间和采集次数进入详情。
- 内容详情从右侧 Sheet 打开，保留当前分页和选材状态。
- 页面首版采用“生成报告”和“报告记录”两个页签，待实际查看后再评估。
- 页面底部固定选材栏，显示已选数量、清空和“生成报告”按钮。
- 点击“生成报告”后才打开确认弹窗。报告名称按日期自动填写并允许修改；内容理解提示词与报告生成提示词上下展示，均提供默认值。
- 提示词修改只对本次报告生效，提供恢复默认值的操作。
- 弹窗展示选材状态数量与只读模型信息，不提供自动化、模型、媒体、时间范围、汇报对象或报告格式设置。
- 提交后自动切换到“报告记录”页签并打开刚创建的任务。
- 任务进度依次表达“补全内容、生成单条总结、汇总报告、完成”，同时展示总数、待处理、处理中和失败数量；完成后列出新总结、复用总结和失败条目。
- 同一时间只允许一份报告生成。活动任务结束前仍可浏览内容和准备选材，但不能提交另一份报告。
- 完成后的报告正文、覆盖情况和来源直接在“报告记录”中展示，不要求再次跳转才能阅读。
- 旧报告统一归入“报告记录”；旧单条处理历史进入对应内容的详情 Sheet，不保留第二套旧工作流入口，也不删除历史数据。
- 大批量选材不设置武断的固定上限；提交弹窗明确展示选中总数、需要处理的数量和模型调用提醒，再由用户确认。
- “报告记录”采用列表加全宽详情：列表显示名称、状态、创建时间和选材数量；有活动任务时自动打开活动任务，否则自动打开最新报告。
- 选材草稿在页签切换和浏览器刷新后保留；只有任务成功创建后才清空。关闭弹窗或提交失败不清空，关闭应用后不承诺永久保留。
- “选中全部未分析内容”把对应条目加入现有选材，不覆盖已经手动勾选的内容。主操作区显示未分析总数及其中曾分析失败的数量，不再提供失败项次级菜单。
- 表头全选只控制当前页二十条；跨全库选材只通过名称明确的批量选材按钮完成。
- 报告记录详情统一承载任务操作：运行中可以取消并保留成果；待人工处理时可以打开专用窗口并显式继续；报告生成失败只重试报告并复用已完成总结。
- 个别条目失败不阻止其余内容生成报告，失败条目留在本次来源处理结果中；没有足够相关内容作为正常空结果展示，不冒充系统失败。

## 页面结构摘要

```text
报告生成
├─ 生成报告
│  ├─ 批量选材操作
│  ├─ 舆情内容 Data Table
│  ├─ 内容详情 Sheet
│  └─ 固定选材栏 → 报告信息弹窗
└─ 报告记录
   ├─ 报告列表
   └─ 当前任务进度或完成报告
```
