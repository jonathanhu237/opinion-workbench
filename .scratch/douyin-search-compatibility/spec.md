- 保留每词条数上限、去重和已有批次恢复方式。
- HTTP 5xx 显示搜索暂不可用，不能误报为内容结构无法识别。
- 用脱敏结构测试覆盖上述行为，并在用户本机验证这次抖音批次可以继续。
- 结果列表允许互动统计缺失或不完整，不能因未知统计拒绝整批内容。
