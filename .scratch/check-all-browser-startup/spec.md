# 检查全部自动打开专用浏览器

问题：重启或首次进入应用时浏览器尚未打开，点击“检查全部”直接请求账号检查，后端返回 browser_not_open；前端 stopBatch 又重置 mutation 错误，导致没有可见提示。

修复：批量流程增加 opening 阶段，先打开专用浏览器，再依次检查平台；打开期间禁止重复启动，异步回调核对批次身份。启动或检查失败时保留错误文案，让用户可以重新点击检查全部。

验证：账号页面 19 项测试、TypeScript 类型检查通过。真实点击按钮自动启动浏览器，微博、抖音、快手、小红书、今日头条五个平台均检查完成且显示已登录，按钮恢复可用。业务采集与报告数据未新增。
