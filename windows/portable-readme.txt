龙田舆情管理 — Windows 免安装版

支持 Windows 10/11 x64。

1. 右键 ZIP 文件，选择“全部解压”。不要直接在压缩包预览窗口启动。
2. 打开解压后的 Longtian 文件夹，双击 Longtian.exe。
3. 程序会使用默认浏览器打开本地页面。无需安装 Python、Node 或开发工具。

请保留整个文件夹，包括 _internal 和 LongtianGalleryWorker.exe；不要只复制主程序。
平台登录和采集需要本机安装 Google Chrome；首次使用需要配置 AI 和登录平台账号。
关闭所有应用页面后，后台服务通常约 10 秒退出。

数据库、配置、凭据、平台登录资料和日志保存在：
解压目录内的 data\ 文件夹（移动程序时必须连同 data 一起移动）。该文件夹含敏感资料，不要分享。
升级时先完全关闭程序并备份旧 data\，再将新版解压到新的文件夹，把旧 data\ 手工复制到新版对应位置；不要复制正在写入的数据库，也不要让脚本自动删除旧目录。
旧版 %LOCALAPPDATA%\LongtianPublicOpinion 资料请在同一 Windows 用户退出应用后手工备份复制。不要同时运行两个版本。
凭据受 Windows 用户保护，不能通过复制文件夹直接迁移到另一台电脑。

若 Windows 提示未知发布者，请先核实来源；不要关闭杀毒软件或系统安全保护。
