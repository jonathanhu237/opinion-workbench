舆情工作台 — Windows 免安装版

支持 Windows 10/11 x64。

1. 右键 ZIP 文件，选择“全部解压”。不要直接在压缩包预览窗口启动。
2. 打开解压后的 OpinionWorkbench 文件夹，双击 OpinionWorkbench.exe。
3. 程序会使用默认浏览器打开本地页面。无需安装 Python、Node 或开发工具。

请保留整个文件夹，包括 _internal 和 OpinionWorkbenchGalleryWorker.exe；不要只复制主程序。
平台登录和采集需要本机安装 Google Chrome；首次使用需要配置 AI 和登录平台账号。
关闭所有应用页面后，后台服务通常约 10 秒退出。

数据库、配置、凭据、平台登录资料和日志保存在：
解压目录内的 data\ 文件夹（移动程序时必须连同 data 一起移动）。该文件夹含敏感资料，不要分享。
本次改名版本是全新空白切换：首次启动会创建空白 data\，不要从旧产品或旧版本复制、导入旧 data\，
也不要复用旧凭据或浏览器登录资料。请在旧应用及专用浏览器完全停止后，把旧程序目录（含其中的
data\）单独保留或备份；删除已经使用过的便携程序目录会删除其内嵌 data\。不要同时运行两个版本。
未来若同一产品的某个版本明确标注为兼容升级，才按该版本说明迁移资料；这不适用于本次改名切换。
凭据受 Windows 用户保护，不能通过复制文件夹直接迁移到另一台电脑。

若 Windows 提示未知发布者，请先核实来源；不要关闭杀毒软件或系统安全保护。
