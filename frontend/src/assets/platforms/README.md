# Platform brand marks

The five SVGs are bundled locally so the application does not make runtime
requests for platform artwork. The four marks added with the multi-platform
collector are colorized variants of the Iconify SVGs listed below; source
paths are recorded so the local copies can be audited without a network call.

Retrieved on 2026-08-25 from the Iconify API endpoint:

- `weibo.svg`: https://api.iconify.design/thesvg-color/sina-weibo.svg

Retrieved on 2026-09-07 from the Iconify API endpoints (the `currentColor`
fill was replaced with the platform brand color used by the UI):

- `douyin.svg`: https://api.iconify.design/logos/tiktok-icon.svg (CC0)
- `kuaishou.svg`: https://api.iconify.design/simple-icons/kuaishou.svg (CC0)
- `toutiao.svg`: https://api.iconify.design/icon-park-outline/jinritoutiao.svg (Apache-2.0)
- `xiaohongshu.svg`: https://api.iconify.design/simple-icons/xiaohongshu.svg (CC0)

The Iconify collection metadata identifies the upstream licenses. The Apache
license text is available from the [IconPark repository](https://github.com/bytedance/IconPark/blob/master/LICENSE);
the Simple Icons and SVG Logos sources are public-domain/CC0 collections.
