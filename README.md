# 舆情工作台

面向单机使用的舆情工具，包含 React 前端、FastAPI 后端，以及使用本机专用 Chrome
运行的微博、抖音、快手、小红书和今日头条登录、采集与文字分析能力。

## 项目结构

```text
frontend/                 React + TypeScript + Vite + shadcn/ui
backend/                  FastAPI 产品后端（独立 uv 环境）
```

产品支持微博（`wb`）、抖音（`dy`）、快手（`ks`）、小红书（`xhs`）和今日头条
（`toutiao`）。采集使用项目自有的原生浏览器边界；仅启动应用或打开页面不会启动浏览器。

在“监控规则”中填写一个或多个**采集对象**（地区、组织、品牌或主题均可）；采集对象是
必填项。**舆情词**为可选项：填写后按每个采集对象与每个舆情词逐对组合搜索，留空时分别
搜索各个采集对象。舆情词只影响内容发现，不是报告相关性的硬性过滤条件。

## 环境要求

- Node.js 24 LTS（建议使用 mise，版本记录在 `frontend/.node-version`）
- pnpm 11
- Python 3.11
- uv
- 本机安装的 Google Chrome（平台登录与采集使用）

## 启动后端

```bash
cd backend
uv sync --locked
uv run fastapi dev --host 127.0.0.1 --port 8000
```

验证接口：

```bash
curl http://127.0.0.1:8000/api/v1/health
```

预期响应：

```json
{"status":"ok","service":"opinion-workbench-api"}
```

## 启动前端

另开一个终端：

```bash
cd frontend
mise x node@24 -- pnpm install --frozen-lockfile
mise x node@24 -- pnpm dev
```

打开 <http://127.0.0.1:5173>。Vite 会把 `/api` 请求代理到本机的 FastAPI 服务；页面
会显示“后端已连接”或可操作的不可用状态。

采集运行时默认选择五个平台，也可以在手动采集或自动任务中调整平台范围。后端使用项目
自有的原生浏览器采集边界；普通平台失败会记录采集缺口，登录或安全验证等人工障碍会
暂停批次，待在专用窗口完成操作后显式继续。

如需覆盖 API 地址，复制 `frontend/.env.example` 为 `.env.local` 并修改
`VITE_API_BASE_URL`。本地环境文件不会进入版本控制。

本次改名版本是一次全新、空白切换：首次启动使用独立的运行目录，不导入旧版本的数据库、
规则、提示词、模型配置、凭据或浏览器登录资料。不要把旧便携包的 `data/` 复制到新版，
旧资料应在旧应用完全停止后单独保留或备份；删除已经使用过的便携目录会一并删除其中的
`data/`。未来若某个版本明确说明是同一产品的兼容升级，应以该版本说明为准，不适用于本次
改名切换。报告生成时分别填写**总结提示词**与**报告提示词**；报告关注范围只由报告提示词
表达，不从采集对象或采集批次自动推断。

## 平台登录与专用浏览器

在“平台账号”中点击“打开专用浏览器”打开或置前项目专用 Chrome 窗口；首次启动只显示
空白标签页。每个平台行的“打开平台”都会在这个窗口中打开对应首页。
再次点击顶部“打开专用浏览器”只置前当前页面。首次使用时，请在这个窗口中登录对应平台；
扫码、验证码和安全验证也由你在该窗口中完成。登录后，点击“检查全部”或对应平台的
“检查状态”读取当前登录状态。

登录状态检查会在时间预算内等待页面恢复已有登录态，再给出结果；不会等待扫码或验证码。
页面初始加载时的空白内容或临时登录按钮不会立即作为最终状态。
完成登录后由你再次发起检查。

专用 Chrome 正常加载网站所需的样式、脚本、认证页面和网络连接，应用不对页面内部
请求逐域名拦截。暂停或取消采集会停止应用的后续搜索、翻页和内容处理，不冻结你正在
操作的登录页面；完成登录或验证后，暂停的采集批次仍需显式继续。

- 无需在日常 Chrome 中开启远程调试或批准本应用连接。应用不会接管日常浏览器，
  也不会从中复制 Cookie。
- 专用窗口使用独立的本地目录 `runtime/opinion-workbench/browser/managed-chrome`，由 Chrome 保留登录态。
  该目录已排除在 Git 之外，不应共享或提交；平台登录过期后仍需重新登录。
- 各平台登录检查和采集中的浏览器操作共用专用窗口。单个任务结束不会关闭整个窗口；
  退出后端应用时会关闭其管理的专用浏览器，但保留登录目录。
- 若提示专用浏览器打开失败，请先确认本机已安装 Chrome。若有残留的专用窗口，关闭它后
  再重新打开；不要删除浏览器目录或锁文件来强行恢复。

## 质量检查

后端：

```bash
cd backend
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

前端：

```bash
cd frontend
mise x node@24 -- pnpm format:check
mise x node@24 -- pnpm lint
mise x node@24 -- pnpm typecheck
mise x node@24 -- pnpm test:run
mise x node@24 -- pnpm build
```
