# 舆情工作台

**围绕你关心的对象，收集多平台内容，用 AI 整理成舆情报告。**

个人电脑上运行的舆情工具，支持微博、抖音、快手、小红书和今日头条。适合关注企业与品牌反馈、地区公共事务，或持续跟进某个事件与话题。

## 可以做什么

- **多平台采集**：填写关注对象，选择平台，搜索并收集相关内容。可以加上“投诉”“欠薪”等舆情词，也可以只搜索对象。
- **积累内容库**：保存历次采集的内容，识别重复命中，保留来源与原帖链接，不必每次从头整理。
- **AI 单条总结**：补全原帖文字，提炼内容要点；总结提示词由你填写，按自己的要求分析。
- **选材生成报告**：从内容库勾选材料，交给 AI 汇总成报告。报告提示词独立配置，由你决定关注什么、怎么写。
- **定时自动任务**：配置采集与分析任务，按计划执行，查看运行进度和历史记录。遇到登录或安全验证时暂停，处理后再继续。
- **本地保存**：内容、配置和报告保存在自己的电脑上。Windows 和 Mac 均提供免安装压缩包。

## 举个例子

想了解“甲公司”和“乙公司”的负面反馈，可以这样设置：

| 配置 | 示例 |
| --- | --- |
| 采集对象 | 甲公司、乙公司 |
| 舆情词（选填） | 投诉、欠薪 |
| 总结提示词 | 提取事件经过、涉及对象、时间和来源陈述，区分事实与指控。 |
| 报告提示词 | 关注甲公司和乙公司的劳动用工问题，按事件归类，保留来源引用和待核查事项。 |

系统分别搜索“甲公司 投诉”“甲公司 欠薪”“乙公司 投诉”“乙公司 欠薪”。舆情词只是帮助发现内容，不要求报告中的每条材料都精确包含这些词。

**搜索什么，由采集规则决定；报告关注什么，由你的报告提示词决定。**

## 开始使用

在 [Releases](https://github.com/jonathanhu237/opinion-workbench/releases) 中选择对应系统的成品 ZIP，而不是 GitHub 自动生成的源码压缩包：

| 系统 | 下载文件 | 解压后启动 |
| --- | --- | --- |
| Windows 10/11 x64 | `OpinionWorkbench-版本-Windows-x64.zip` | 双击 `OpinionWorkbench.exe` |
| Mac Apple Silicon | `OpinionWorkbench-版本-macOS-arm64.zip` | 双击 `启动.command` |

> 当前 `v0.2.0` 为 Release 草稿，仅有仓库权限的账号可以查看，尚未公开下载。Mac 包不支持 Intel 机型。

无需安装 Python 或 Node。采集需要本机安装 **Google Chrome**；AI 分析需要配置模型服务及 API Key，调用可能产生费用。

1. **解压完整文件夹并启动**，应用会在浏览器中打开。
2. **配置模型、登录平台**，平台登录在应用打开的专用 Chrome 窗口中完成。
3. **添加采集对象，开始采集**，或设置定时自动任务。
4. **选取内容，填写提示词，生成报告**。

## 使用前了解

- **分析的是原帖文字**，不会识别图片、视频画面或声音。文字不足的材料会提示人工查看原帖；AI 判断仍需核查。
- **采集受平台限制**，不保证全网覆盖或搜索结果完整。登录失效、安全验证及平台限制可能需要人工处理。
- **本地运行不等于离线**：采集会访问平台，AI 分析会把相关材料发送给你配置的模型服务。
- **不要分享使用过的整个文件夹**：便携版的 `data/` 包含内容、配置和登录资料。删除该文件夹会同时删除其中的数据。
- **v0.2.0 从空白开始**：不导入旧产品资料，请另行保留旧目录，不要把旧 `data/` 复制进新版。

未签名程序可能触发系统安全提示，请核实下载来源后按系统提示授权，不要关闭全局安全保护。
